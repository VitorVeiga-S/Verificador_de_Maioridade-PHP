# Verificador de Maioridade em PHP

Projeto desenvolvido para a Atividade 3: Desafio "Verificador de Maioridade", focado no recebimento de dados de formulário via POST, validação de idade e gravação em arquivo.

## Como funciona

O script recebe o nome e o ano de nascimento do usuário e calcula a idade.

- **Maior de idade (18 anos ou mais):** mostra a mensagem de acesso permitido e salva o nome e a idade no arquivo `log_acessos.txt`.
- **Menor de idade:** mostra a mensagem de acesso negado e não grava o registro.

## Arquivos

- `5a_desafio1.php`: arquivo principal com o formulário e a lógica.
